# 個人網頁設計｜吳驊家

## 專案內容
- index.html：網頁內容與區塊結構
- style.css：Frutiger Aero 視覺風格、版面與響應式設計
- script.js：導覽列、目前區塊提示、進場動畫、回到頂部
- assets/：你提供的南臺科大校徽、NMIXX 照片、大尾鱸鰻電影海報

## 使用方式
1. 將 ZIP 解壓縮。
2. 使用 VS Code 開啟 `Personal_Website_Project` 資料夾。
3. 確認 `index.html`、`style.css`、`script.js` 和 `assets` 資料夾都在同一個專案資料夾內。
4. 在 VS Code 安裝 Live Server 擴充功能（若尚未安裝）。
5. 對 `index.html` 按右鍵，選擇 **Open with Live Server**。

也可以直接用瀏覽器開啟 index.html。Google Fonts 需要網路連線；沒有網路時會使用系統備用字型。
